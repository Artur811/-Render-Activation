КОМПЛЕКТ ДЛЯ RENDER — ТЕСТ, НЕ ГОТОВАЯ ЗАЩИЩЁННАЯ ИГРА

Можно настраивать из браузера телефона. Render подключается к репозиторию,
а не запускает прикреплённый ZIP напрямую.

1. Распакуйте ZIP на телефоне.
2. Создайте репозиторий GitHub. Загрузите в его корень app.py,
   requirements.txt и render.yaml. Не загружайте ZIP вместо файлов.
   На телефоне может понадобиться режим «Версия для ПК» в браузере.
3. В Render выберите New > Blueprint и подключите этот репозиторий.
4. Перед подтверждением убедитесь: и Web Service, и PostgreSQL — Free.
   Если Free недоступен, остановитесь, не выбирайте платный план.
5. Дождитесь развёртывания. Откройте адрес Web Service.
6. В Render: ваш Web Service > Environment > ADMIN_SECRET.
   Скопируйте значение в поле «Ключ администратора» на странице сервиса.
7. Нажмите «Создать код». Скопируйте code, выдайте человеку.
8. Для отключения используйте ID лицензии из списка.

Не передавайте ADMIN_SECRET и TOKEN_SECRET другим и не вставляйте их
в приложение. Храните защищённую резервную копию этих значений.

ВАЖНО О БЕСПЛАТНОМ RENDER
Web Service засыпает после 15 минут без запросов. Пробуждение может занимать
около минуты. Бесплатная PostgreSQL истекает через 30 дней.
Это НЕ постоянное бесплатное хранилище лицензий.
Не используйте SQLite/локальные JSON для кодов: файловая система временная.
Не подключайте платный план или карту, если не хотите расходов.
Перед подтверждением проверьте актуальные условия Render.
До окончания 30 дней нужно решить вопрос с долговременным хранилищем.

ИНТЕГРАЦИЯ APK — НЕ ВЫПОЛНЕНА
Загруженный Brawl Stars не изменён. Коды пока не открывают эту игру.
Сервер реализует:
POST /activate {"code":"...","installation_id":"случайный ID от 20 символов"}
  -> {"license_id":"...","token":"..."}
POST /verify {"license_id":"...","installation_id":"...","token":"..."}
  -> {"active":true}
Клиент должен сохранять данные приватно и проверять активацию по HTTPS.
Повтор с той же installation_id допустим, другая установка получает отказ.
Привязка к installation_id — не аппаратная защита: клонирование данных и
обход проверки изменённым клиентом остаются возможными.
Ручное восстановление: отключить старую лицензию и выдать новый код.
Ограничение частоты запросов и защита от злоупотреблений не реализованы.
Для публичного использования нужен дополнительный аудит безопасности.

ПРОВЕРЕНО: синтаксис Python, локальные тесты маршрутов с имитацией базы.
НЕ ПРОВЕРЕНО: живое развёртывание Render, настоящая PostgreSQL и APK.
