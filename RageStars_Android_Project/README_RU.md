RageStars Android companion source. Includes draggable floating RS button, visual-only three-tab menu, one-time activation screen and encrypted local token storage using Android Keystore. Does not modify Brawl Stars or contain gameplay cheats. Open in Android Studio with JDK 17 and SDK 35. Before building, set BASE_URL in Api.java to the actual deployed RageStars backend. Render deployment is not yet confirmed. This is a separate companion APK, not integrated into the existing BRF binary APK.
